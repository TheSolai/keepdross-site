What it does

⌨️

Tab = proofread

Press Tab to proofread the current sentence with Apple Intelligence. No selection needed — just put your cursor anywhere in a sentence and hit Tab. Press again to accept the suggestion or keep typing to dismiss it.

📁

Plain .md chapters

Each project is a folder of plain Markdown files — one chapter, one file. No proprietary format. No lock-in. Your prose is yours forever, in files you can open anywhere.

🔒

100% on-device

Your writing never leaves your Mac. Pencil uses Apple Intelligence's on-device Foundation Models — the same model that runs in Messages and Notes. No API calls. No cloud. No telemetry.

↩️

Cmd-Z works

Undo is native. Pencil uses standard NSTextStorage mutations — the system undo stack works exactly as you'd expect. Accept a correction and change your mind? Cmd-Z brings it back.

🔍

Spell check built-in

Red squiggles as you type. Grammar suggestions. Pencil uses macOS's built-in spell checker — no setup, no accounts. It just works while you write.

📥

Falls back gracefully

Apple Intelligence disabled? Pencil automatically falls back to NSSpellChecker — so Tab still works, just with basic spell-checking. You never lose functionality.

How Tab works

// You type:

// Cursor is in the sentence. You press Tab.
// Pencil: checking...
// ✓ Done in 0.9s
She went to the market yesterday and bought some apples.
// Accept with Tab again. Dismiss by keep typing. Undo with Cmd-Z.
